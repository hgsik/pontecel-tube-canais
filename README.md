# PonteCel-Tube: lista de canais

- `tube.json`: perfis → categorias → canais lidos pelo app PonteCel-Tube. Para mudar a lista, edite este arquivo
  (o app baixa a versão nova ao abrir; suba o número de `versao`).
- `espelho/`: cópia dos feeds públicos do YouTube, atualizada a cada hora pelo GitHub Actions (`espelho.py`). O app
  usa essa cópia quando o YouTube não responde.
